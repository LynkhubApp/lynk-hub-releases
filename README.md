# Lynk Hub — релизы

Неофициальное приложение для головного устройства Lynk & Co 900 (Flyme Auto):
плавающая иконка и панель с разделами «Музыка», «VPN», «Приложения», «Машина»,
строка с треком на проекции.

Здесь только готовые APK. Устанавливать удобнее через «Установщик Lynk Hub»
на Android-телефоне: он сам подключится к машине, поставит приложение
и выдаст нужные разрешения. Обновления Lynk Hub потом скачивает сам.

Приложение не связано с Lynk & Co, Geely или Flyme.
